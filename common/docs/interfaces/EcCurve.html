    Interface EcCurve

    Curve-specific parameters for EcDhkemPrimitives.

    Pass one of EC_P_256, EC_P_384 or EC_P_521 to the EcDhkemPrimitives constructor. Keeping them as separate constants (instead of selecting them by KEM ID as the deprecated Ec does) lets bundlers drop the parameters of the curves that are not used.
